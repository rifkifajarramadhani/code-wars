## About

This repository documents my ongoing practice on [CodeWars](https://www.codewars.com/), a platform built around programming challenges called *kata*. Each solution is an opportunity to improve algorithmic thinking, explore language features, and compare different approaches to the same kind of problem.

The collection currently includes solutions written in JavaScript and Go. Kata are grouped by their CodeWars rank: `8 kyu` is the most approachable level, while lower kyu numbers represent increasingly difficult challenges.

## Repository structure

Solutions are organized first by programming language and then by kata difficulty:

```text
code-wars/
├── javascript/
│   ├── 6-kyu/
│   ├── 7-kyu/
│   └── 8-kyu/
├── go/
│   ├── 8-kyu/
│   └── runner.go
└── README.md
```

Files use a zero-padded sequence number followed by a descriptive kata name, for example:

- [`javascript/6-kyu/001-multiple-3-or-5.js`](./javascript/6-kyu/001-multiple-3-or-5.js)
- [`javascript/7-kyu/001-disemvowel-trolls.js`](./javascript/7-kyu/001-disemvowel-trolls.js)
- [`go/8-kyu/001-volume-of-a-cuboid.go`](./go/8-kyu/001-volume-of-a-cuboid.go)

## Exploring the solutions

1. Choose a language directory.
2. Open a folder matching the kata rank you want to explore.
3. Select a solution file by its sequence number and title.
4. Follow the CodeWars URL in the file comment to read the original challenge.

The files are individual kata submissions rather than a packaged application. There is currently no shared installation command or automated test suite in this repository; solutions are intended to be read alongside their corresponding challenges and evaluated on CodeWars.

## Practice workflow

For each practice session, I aim to:

1. Read the kata requirements and identify edge cases.
2. Build a clear working solution in the chosen language.
3. Submit and validate the solution on CodeWars.
4. Save the final approach under the matching language and kyu directory.

## Conventions

- Keep each kata solution focused on a single challenge.
- Include the original CodeWars challenge URL in the file comment when available.
- Group solutions by language and CodeWars rank.
- Name files with a three-digit sequence and a readable kebab-case title.

## A note on spoilers

These files contain completed solutions. If you are working through the same kata, consider attempting the challenge yourself before reading an implementation—the struggle is where most of the learning happens.
